This project is based on Windows System Administration and Task Automation. It demonstrates practical knowledge of Windows operating system utilities, command-line operations, batch scripting, and PowerShell automation.

6. How to Execute the Scripts

- Task 4: Batch Script

Open the Task4_Batch_Script folder.

Locate system_check.bat.

Double-click the file.

The script will display basic Windows system information.

Press any key to close the CMD window.

- Task 5: PowerShell Script

Open PowerShell.

Navigate to the Task5_PowerShell_Script directory.

Run the following commands:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\System_Check.ps1

The script displays system information and demonstrates basic file creation and backup operations.
