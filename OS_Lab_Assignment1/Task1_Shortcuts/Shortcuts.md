                        #Windows Keyboard Shortcuts#

*Objective*

The objective of this task is to learn and demonstrate commonly used Windows keyboard shortcuts. These shortcuts help users perform daily computer operations quickly, improve productivity, manage applications and navigate the Windows operating system efficiently.


Shortcuts and Their Functions

*A. System and Navigation Shortcuts*

Shortcut             |   Function

Win + E              |  Opens File Explorer

Win + R              |  Opens the Run dialog box

Win + X              |  Opens the Quick Link menu

Win + I              |  Opens Windows Settings

Win + L              |  Locks the computer

Win + D              |  Shows or hides the desktop

Win + M              |  Minimizes all open windows

Win + Shift + M      |  Restores minimized windows

Win + Tab            |  Opens Task View

Win + S              |  Opens Windows Search

Win + A              |  Opens Action Center in Windows 10

Win + U              |  Opens Ease of Access settings

Win + P              |  Opens display projection options

Win + K              |  Opens the Connect panel

Win + V              |  Opens Clipboard History (when enabled)


*B. Window Management Shortcuts*

Shortcuts             |          Function

Win + Left Arrow      |   Snaps the active window to the left

Win + Right Arrow     |   Snaps the active window to the right

Win + Up Arrow        |   Maximizes the active window

Win + Down Arrow      |   Restores or minimizes the active window

Alt + Tab             |   Switches between open applications

Alt + F4              |   Closes the active application or window

Win + Home            |   Minimizes all windows except the active one

Win + Shift + Left Arrow   |  Moves a window to the left monitor

Win + Shift + Right Arrow  |  Moves a window to the right monitor

Win + Ctrl + D        |    Creates a new virtual desktop


*C. File and Folder Management Shortcuts*

No.

Shortcut                |        Function

Ctrl + C                |  Copies selected files or text

Ctrl + X                |  Cuts selected files or text

Ctrl + V                |  Pastes copied or cut content

Ctrl + A                |  Selects all items

Ctrl + Z                |  Undoes the last action

Ctrl + Y                |  Redoes the last action

F2                      |  Renames the selected file or folder

F5                      |  Refreshes the current window

Shift + Delete          |  Permanently deletes selected items

Alt + Enter             |  Opens properties of the selected item


*D. Text Editing and Application Shortcuts*

Shortcut                 |          Function

Ctrl + S                 |   Saves the current document

Ctrl + P                 |   Opens the Print dialog

Ctrl + F                 |   Finds specific text

Ctrl + N                 |   Opens a new window or document

Ctrl + O                 |   Opens an existing file

Ctrl + W                 |   Closes the current document or tab

Ctrl + B                 |   Makes selected text bold

Ctrl + I                 |   Makes selected text italic

Ctrl + U                 |   Underlines selected text

Ctrl + Home              |   Moves the cursor to the beginning of a document

Ctrl + End               |   Moves the cursor to the end of a document



*E. Security, Accessibility and Additional Shortcuts*


Shortcut                  |            Function

Ctrl + Shift + Esc        |   Opens Task Manager

Ctrl + Alt + Delete       |   Opens Windows security options

Win + Shift + S           |   Opens the screen snipping tool

Win + .                   |   Opens the Emoji panel

Win + G                   |   Opens Xbox Game Bar

Win + H                   |   Opens voice typing

Win + Ctrl + Left Arrow   |   Switches to the virtual desktop on the left

Win + Ctrl + Right Arrow  |   Switches to the virtual desktop on the right

Win + Ctrl + F4           |   Closes the current virtual desktop



*Importance of Keyboard Shortcuts*

- Time Saving: Shortcuts reduce the time required to perform common operations.

- Productivity: Users can work more efficiently without repeatedly using the mouse.

- System Navigation: Shortcuts provide quick access to different Windows features.

- File Management: Users can copy, move, rename and delete files easily.

- Security: Shortcuts such as Win + L help protect the computer from unauthorized access.

*Conclusion*

Windows keyboard shortcuts are important tools for efficient system administration and everyday computer usage. They help users manage files, navigate applications, access system settings and perform different operations quickly. Learning these shortcuts improves productivity, saves time and provides better control over the Windows operating system.
